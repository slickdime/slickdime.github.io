# slickdime.com

Static site for SLICK DIME LLC and the BizCard app, served by GitHub Pages at https://slickdime.com.

- `bizcard/privacy/`, `bizcard/terms/`, `bizcard/support/`, `bizcard/delete-account/`: pages the app stores and the app link to
- `app-ads.txt`: add your AdMob line once you have a publisher ID
- `CNAME`: the custom domain for GitHub Pages
